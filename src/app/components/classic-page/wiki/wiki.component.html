Overview

Hordes is a single-player survival strategy game where you are the last human alive in a ruined city. Each night, waves of zombies attack your defenses. Each day, you scavenge, build, and learn in an effort to survive one more night.

⚙️ Game Systems

🕐 The Daily Cycle

  1. Daytime — Search, build, or learn before midnight. Each action consumes time.
  2. Nighttime (Midnight Attack) — The horde attacks. Survive if defense ≥ zombie count.

🧱 Buildings

Buildings cost resources and time to construct. Most increase your defense.

Building Max Level Description
🏗 Architect Shelter 3 Increases discovery odds for new building plans.
📚 Library 3 Increases discovery odds for new skill levels.

🧠 Skills

Each skill improves a specific aspect of survival. Effects are linear per level.

Skill Max Level Effect per Level Level 5 / 8 Effect
💤 Insomniac 8 Wake up 15 min earlier each day. 2 hours earlier wake-up.
⛏ Digger 5 Reduce search time linearly. Action time ÷ 2.
🧱 Builder 5 Reduce building time linearly. Action time ÷ 2.
📖 Fast Learner 5 Reduce learning time linearly. Action time ÷ 2.

⚔️ Defense and Attacks

  • All buildings (except special ones) add defense points.
  • The zombie horde increases nightly.
  • Defense ≥ Zombies → Survive; otherwise you die.

💡 Experience & Levels

Gain XP equal to zombies defeated. Player level uses a logarithmic curve. Each level grants +1 minute earlier wake-up.

🧮 Ranked Mode

Asynchronous deterministic competition using seeded runs. Identical challenges for both players.

  • Compare performance: days survived, defenses built.
  • Elo-like ranked point system.
  • Global & performance leaderboards.

🧩 Strategy Tips

  • Upgrade Libraries to unlock higher skill caps.
  • Architect Shelters unlock stronger defense plans.
  • In Ranked Mode, efficiency beats luck.
